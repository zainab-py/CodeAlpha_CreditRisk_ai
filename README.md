# CreditRisk AI

### Explainable Credit Risk Prediction & What-If Analysis

CreditRisk AI is a machine learning application that estimates the probability of a credit applicant being classified as a **good or bad credit risk** based on historical financial and demographic information.

The project combines a machine learning pipeline with an interactive **Streamlit dashboard**, allowing users to enter applicant information, view prediction probabilities, understand the resulting risk level, and experiment with different credit amounts through a what-if analysis.

> **Note:** The risk score generated by this application is a model-derived score for demonstration purposes. It is not an official credit score and should not be used as a real-world lending decision.

## How It Works

The application follows a simple machine learning workflow:

```text
Applicant Data
      ↓
Data Preprocessing
      ↓
Feature Engineering
      ↓
Random Forest Model
      ↓
Credit Risk Probability
      ↓
Risk Score & Category
      ↓
Interactive Streamlit Dashboard
```

The model processes applicant information such as:

* Credit history
* Loan duration
* Credit amount
* Savings status
* Employment
* Installment rate
* Housing
* Existing credits
* Age
* Dependents
* Other debtors
* Telephone availability
* Foreign worker status

## Feature Engineering

Three additional features are derived from the applicant's existing information:

### Credit-to-Age Ratio

```text
Credit Amount / Age
```

This provides a normalized view of the requested credit amount relative to the applicant's age.

### Duration-to-Age Ratio

```text
Loan Duration / Age
```

This relates the repayment duration to the applicant's age.

### Monthly Credit Burden

```text
Credit Amount / Loan Duration
```

This provides an approximate monthly credit burden based on the available loan information.

## Machine Learning

The project uses a supervised classification approach.

### Random Forest

The primary model is a **Random Forest classifier**, which combines multiple decision trees to make a final classification.

The model produces probabilities for:

```text
Good Credit
Bad Credit
```

The bad-credit probability is then used to derive the application's model-based risk score.

### Risk Score

The application converts the predicted probability of bad credit into a simple 0–100 model-derived score:

```text
Risk Score = 100 - (Probability of Bad Credit × 100)
```

The application then categorizes the result as:

| Bad Credit Probability | Category      |
| ---------------------- | ------------- |
| < 30%                  | Low Risk      |
| 30%–59.99%             | Moderate Risk |
| ≥ 60%                  | High Risk     |

These thresholds are application-defined demonstration thresholds and are not industry-standard credit-rating categories.

---

## Model Evaluation

The project evaluates the classification model using metrics relevant to credit-risk prediction:

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC

Particular attention is given to **Recall**, since missing applicants who are actually classified as bad credit can be important in a risk-screening setting.

## What-If Analysis

One of the main features of CreditRisk AI is the interactive what-if simulator.

Users can change the proposed credit amount and immediately observe how the model's predicted bad-credit probability changes.

For example:

```text
Original Credit Amount
        ↓
Model Prediction
        ↓
Change Credit Amount
        ↓
New Model Prediction
        ↓
Compare Results
```

This makes the application more interactive than a simple classification interface.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/credit-risk-ai.git
```

Move into the project directory:

```bash
cd credit-risk-ai
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Running the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.
